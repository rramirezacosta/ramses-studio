Ramses Studio

A desktop practice tool for musicians. Import a WAV, FLAC, or MP3 recording and split it into individual stems with local ONNX Runtime inference — completely offline.

Download latest release View on GitHub

Features

Six-stem separation

Bundled HTDemucs ONNX model splits tracks into drums, bass, other, vocals, guitar, and piano.

DAW-style timeline

Load separated stems into track lanes with waveforms, mute/solo, volume, pan, and per-track controls.

Section looping

Drag over a waveform to create practice loops of the sections you are rehearsing.

Local-first

Inference, songs, and generated WAV stems stay on your machine. No accounts, no uploads.

Audio decoding

Bundled FFmpeg handles WAV, FLAC, and MP3 imports; yt-dlp integration supports YouTube audio sources.

Web Audio transport

Mixing playback via the Web Audio API with a shared transport state and window-level controls.

Getting started

Requires Node.js 20 or newer, npm, Git LFS, plus FFmpeg and yt-dlp binaries in vendor/.

git clone git@github.com:rramirezacosta/ramses-studio.git
cd ramses-studio
git lfs install
git lfs pull
npm install
npm run dev

Usage

  1. Select Import Audio (or paste a YouTube URL) to decode a recording.
  2. Wait for separation to complete; the generated stems are added to the song library.
  3. Select the song to open its tracks in the timeline.
  4. Use M and S on each track to mute or solo it, adjust its volume and pan, and drag over a waveform to create a loop.

All separation happens in a background worker thread so the interface stays responsive while the model runs.
